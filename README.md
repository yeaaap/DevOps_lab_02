# Лабораторная работа 2 — Инструменты DevOps

Лебедев Максим Евгеньевич, БИСТ-23-ПО-3. Вариант 10.

Проект содержит Flask-сервис с эндпоинтами `/`, `/me` и `/version`.
Используемые параметры: `python:3.11-slim`, порт приложения 5010,
порт публикации 8030, слово-маркер `weblab`.

## Сборка и запуск

Из каталога проекта:

```bash
docker build --build-arg VERSION=1.0 -t lebedev-10/probe:0.9 .
docker run -d --name lebedev-10-web -p 8030:5010 lebedev-10/probe:0.9
curl http://127.0.0.1:8030/me
curl http://127.0.0.1:8030/version
```

`/version` возвращает JSON со значением из `/app/VERSION` и словом-маркером.

## Остановка

```bash
docker rm -f lebedev-10-web
```

## Состав проекта

- `Dockerfile` — установка зависимостей, параметры окружения.
- `.dockerignore` — исключение дампов, окружения, кешей и служебных файлов.
- `app.py` — код сервиса и данные студента.
- `requirements.txt` — Flask 3.0.3.
